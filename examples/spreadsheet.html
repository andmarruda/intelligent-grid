Spreadsheet features

Drag over cells to select a range, then Ctrl+C, Ctrl+V or Delete. Drag the small square on the corner of the range to fill a series (try the qty column, or the code column with A001). Ctrl+Z undoes, Ctrl+F / Ctrl+H / Ctrl+G find, replace and go to, Shift+F2 edits a cell comment. The Import button reads a CSV or XLSX file (export one first to try).
