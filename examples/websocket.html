Infinite scroll over a WebSocket

One connection (sorla.connect('ws://…/ws/orders'), sorla-db 1.7) carries every page: scrolling sends { type: 'load', offset, limit, sort, where } and the server answers on the same socket. The demo backend also changes a random order every 3 seconds (another user): the change is pushed and the row updates in place, without reloading. Sort or filter a column: the request goes to the server. Run npm run demo.
