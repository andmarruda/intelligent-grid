Loading 100 000 rows in blocks with Server-Sent Events

grid.loadStream('/api/orders/stream') opens one Server-Sent Events stream; the demo backend sends the orders in blocks of 5 000 (event: rows, each with an id:). The rows show up as each block arrives and you can scroll, sort and filter while it loads. If the connection drops, the client reconnects with Last-Event-ID and the server continues with the next block. Run npm run demo.
