# Internationalization

```ts
new IntelligentGrid('#grid', { locale: 'pt-BR', ... });
```

`locale` (default: the browser language) drives:

| | en-US | pt-BR |
|---|---|---|
| Numbers | `1,234.56` | `1.234,56` |
| Currency (default) | `$1,234.56` (USD) | `R$ 1.234,56` (BRL) |
| Dates | `10/28/2026` | `28/10/2026` |
| Typed input | `1,234.56`, `10/28/2026` | `1.234,56`, `1,5`, `28/10/2026` |
| CSV export | `,` delimiter, `.` decimals | `;` delimiter, `,` decimals |
| XLSX date format | `mm/dd/yyyy` | `dd/mm/yyyy` |
| Sorting | locale collation, accents and case ignored | same, Portuguese rules |
| Formulas | `"a"&1.5` → `a1.5`, `VALUE("1,234.5")` = 1234.5 | `"a"&1.5` → `a1,5`, `VALUE("1.234,5")` = 1234.5 |
| UI labels | English | Portuguese |

Default currencies: pt-BR BRL, en-US USD, en-GB GBP, es-ES/de-DE/fr-FR EUR, otherwise USD.
Override with the grid `currency` option or per column.

Formula syntax itself does not change with the locale: function names are English (`SUM`, `IF`),
and decimals in formulas use `.`. Both `,` and `;` work as argument separators.

## Labels

UI texts ship in English and Portuguese (`pt`, `pt-BR`). Override any key, or translate everything
for another language, with `labels`:

```ts
labels: {
    search: 'Buscar pedido…',
    noRows: 'Nada por aqui',
    status: '{shown} / {total} pedidos',
    min: 'Valor mínimo: {0}'
}
```

| Keys | Used in |
|---|---|
| `search`, `clearFilters`, `columns`, `addRow`, `deleteRows`, `exportCsv`, `exportXlsx` | Navbar |
| `sortAsc`, `sortDesc`, `clearSort`, `filter`, `apply`, `clear`, `selectAll`, `blanks`, `and`, `or` | Filter menu |
| `op_contains`, `op_notContains`, `op_equals`, `op_notEquals`, `op_startsWith`, `op_endsWith`, `op_empty`, `op_notEmpty`, `op_eq`, `op_ne`, `op_gt`, `op_gte`, `op_lt`, `op_lte`, `op_between` | Filter operators |
| `noRows`, `loading`, `loadError` | Messages |
| `status` (`{shown} of {total} rows`), `selected` (`{count} selected`), `confirmDelete` (`Delete {count} row(s)?`) | Status bar / dialogs |
| `changesCount`, `changesDetail`, `discardChanges`, `confirmDiscard`, `was` | Change tracking |
| `confirmTitle`, `deleteTitle`, `confirm`, `cancel`, `discard` | Confirmation modal |
| `advancedFilter`, `addRule`, `addGroup`, `removeRule`, `removeGroup`, `not`, `join`, `field`, `operator`, `value`, `queryJson`, `copyJson`, `copied`, `previewRows`, `queryEmpty`, `op_in`, `op_nin`, `q_in`, `q_nin` | Advanced filter |
| `undo`, `redo` | Undo / redo buttons |
| `find`, `findNext`, `findPrevious`, `findCount` (`{current} of {count}`), `noMatches`, `matchCase`, `wholeCell`, `replace`, `replaceAll`, `replaceWith`, `replacedCount`, `goTo`, `goToHint`, `close` | Find / replace / go to bar |
| `expandGroup`, `collapseGroup`, `blankGroup` | Group rows |
| `importFile`, `importDone`, `importErrors` (`{count}`, `{errors}`), `confirmImport` | Import button |
| `comment`, `saveComment`, `deleteComment` | Comment editor |
| `required`, `invalidValue`, `invalidNumber`, `invalidInteger`, `invalidDate`, `invalidBoolean`, `invalidOption`, `pattern`, `min`, `max`, `minLength`, `maxLength` | Validation (`{0}` = the rule value) |
| `true`, `false` | Boolean filter values |

To add a built-in language, add a dictionary to `src/i18n/labels.ts`.
