# Internacionalização

```ts
new IntelligentGrid('#grid', { locale: 'pt-BR', ... });
```

`locale` (padrão: o idioma do navegador) define:

| | en-US | pt-BR |
|---|---|---|
| Números | `1,234.56` | `1.234,56` |
| Moeda (padrão) | `$1,234.56` (USD) | `R$ 1.234,56` (BRL) |
| Datas | `10/28/2026` | `28/10/2026` |
| Entrada digitada | `1,234.56`, `10/28/2026` | `1.234,56`, `1,5`, `28/10/2026` |
| Exportação CSV | delimitador `,`, decimais com `.` | delimitador `;`, decimais com `,` |
| Formato de data no XLSX | `mm/dd/yyyy` | `dd/mm/yyyy` |
| Ordenação | collation da localidade, ignorando acentos e maiúsculas/minúsculas | o mesmo, com as regras do português |
| Fórmulas | `"a"&1.5` → `a1.5`, `VALUE("1,234.5")` = 1234.5 | `"a"&1.5` → `a1,5`, `VALUE("1.234,5")` = 1234.5 |
| Rótulos da interface | inglês | português |

Moedas padrão: pt-BR BRL, en-US USD, en-GB GBP, es-ES/de-DE/fr-FR EUR; nos demais casos, USD.
Sobrescreva com a opção `currency` da grade ou por coluna.

A sintaxe das fórmulas em si não muda com a localidade: os nomes das funções são em inglês (`SUM`, `IF`),
e os decimais nas fórmulas usam `.`. Tanto `,` quanto `;` funcionam como separadores de argumentos.

## Rótulos

Os textos da interface vêm em inglês e em português (`pt`, `pt-BR`). Sobrescreva qualquer chave, ou traduza tudo
para outro idioma, com `labels`:

```ts
labels: {
    search: 'Buscar pedido…',
    noRows: 'Nada por aqui',
    status: '{shown} / {total} pedidos',
    min: 'Valor mínimo: {0}'
}
```

| Chaves | Uso |
|---|---|
| `search`, `clearFilters`, `columns`, `addRow`, `deleteRows`, `exportCsv`, `exportXlsx` | Barra de navegação |
| `sortAsc`, `sortDesc`, `clearSort`, `filter`, `apply`, `clear`, `selectAll`, `blanks`, `and`, `or` | Menu de filtro |
| `op_contains`, `op_notContains`, `op_equals`, `op_notEquals`, `op_startsWith`, `op_endsWith`, `op_empty`, `op_notEmpty`, `op_eq`, `op_ne`, `op_gt`, `op_gte`, `op_lt`, `op_lte`, `op_between` | Operadores de filtro |
| `noRows`, `loading`, `loadError` | Mensagens |
| `status` (`{shown} of {total} rows`), `selected` (`{count} selected`), `confirmDelete` (`Delete {count} row(s)?`) | Barra de status / diálogos |
| `changesCount`, `changesDetail`, `discardChanges`, `confirmDiscard`, `was` | Rastreamento de alterações |
| `confirmTitle`, `deleteTitle`, `confirm`, `cancel`, `discard` | Modal de confirmação |
| `advancedFilter`, `addRule`, `addGroup`, `removeRule`, `removeGroup`, `not`, `join`, `field`, `operator`, `value`, `queryJson`, `copyJson`, `copied`, `previewRows`, `queryEmpty`, `op_in`, `op_nin`, `q_in`, `q_nin` | Filtro avançado |
| `undo`, `redo` | Botões de desfazer / refazer |
| `find`, `findNext`, `findPrevious`, `findCount` (`{current} of {count}`), `noMatches`, `matchCase`, `wholeCell`, `replace`, `replaceAll`, `replaceWith`, `replacedCount`, `goTo`, `goToHint`, `close` | Barra de localizar / substituir / ir para |
| `expandGroup`, `collapseGroup`, `blankGroup` | Linhas de grupo |
| `importFile`, `importDone`, `importErrors` (`{count}`, `{errors}`), `confirmImport` | Botão de importação |
| `comment`, `saveComment`, `deleteComment` | Editor de comentários |
| `required`, `invalidValue`, `invalidNumber`, `invalidInteger`, `invalidDate`, `invalidBoolean`, `invalidOption`, `pattern`, `min`, `max`, `minLength`, `maxLength` | Validação (`{0}` = o valor da regra) |
| `true`, `false` | Valores do filtro booleano |

Para adicionar um idioma embutido, adicione um dicionário em `src/i18n/labels.ts`.
